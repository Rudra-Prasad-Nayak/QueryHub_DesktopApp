## 🚀 Overview

QueryHub is a modern desktop SQL productivity application built for developers, database engineers, students, analysts and non-technical users who want to work with SQL faster and more efficiently.

Instead of manually remembering complex SQL syntax across multiple database systems, QueryHub provides a structured no-code workflow where users can generate advanced SQL queries through intuitive input forms.

Built using Electron, React, TypeScript and Vite.

---

# ✨ Features

## ✅ No-Code SQL Generation

Generate SQL queries by filling simple forms.

Supported query generation includes:

- CREATE TABLE
- ALTER TABLE
- INSERT
- UPDATE
- DELETE
- SELECT
- MERGE
- INDEXES
- VIEWS
- MATERIALIZED VIEWS
- PARTITIONS
- SUBPARTITIONS
- STORED PROCEDURES
- FUNCTIONS
- TRIGGERS
- TCL Commands
- DCL Commands
- DML Commands
- Constraints & Relationships

---

## ✅ Multi-Database Support

Supports multiple database dialects:

- Oracle
- MySQL
- PostgreSQL
- SQL Server

---

## ✅ SQL Validation

Validate SQL queries with dialect-aware validation support.

---

## ✅ SQL Conversion

Convert queries between database dialects.

Examples:

- Oracle → MySQL
- MySQL → PostgreSQL
- SQL Server → Oracle

---

## ✅ SQL Optimization

Analyze and optimize SQL queries for better performance.

Features include:

- Query analysis
- Optimization suggestions
- Index recommendations

---

## ✅ SQL Formatting

Beautify and format SQL queries for better readability.

---

## ✅ Export SQL Files

Download generated queries as `.sql` files.

---

## ✅ Offline Desktop Application

Works completely offline as a native desktop application.
